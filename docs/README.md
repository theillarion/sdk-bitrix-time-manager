# Документация Python SDK Bitrix Time-manager

Дата: **8 октября 2026 года**. Версия пакета: **0.1.0**.

Документы описывают самостоятельный пакет `bitrix-time-manager`: асинхронную
Python-библиотеку и CLI `bitrix-time`. Основной способ
подключения к приложениям, включая Telegram-бота, — вызов публичных Python-методов
в том же процессе. Отдельный HTTP-сервер для этого не требуется.

## Как читать

- **TR-01–TR-18** — технические требования к существующим функциям SDK.
- **NFR-01–NFR-05** — требования к качеству и сопровождению с указанными границами.
- **UC-01–UC-14** — сценарии использования и критерии приёмки.
- **LIM-01–LIM-10** — ограничения и открытые вопросы.
- **CHK-01–CHK-08** — группы проверок. Пустой флажок означает пункт для очередной
  проверки, а не утверждение, что функция отсутствует или уже проверена.

Это спецификация текущего поведения по исходникам и тестам. Предлагаемые
улучшения обозначены отдельно и не считаются реализованными. Наличие требования
или сценария не доказывает выполнение всех его проверок на реальном портале.

Исходные материалы: [pyproject.toml](../pyproject.toml),
[исходники](../src/bitrix_time_manager), [тесты](../tests),
[историческая проверка портала](../verification.json).
При подготовке документации 8 октября 2026 года прошли 32 текущих теста SDK
и CLI с подменённым транспортом. Проверены локальные ссылки, идентификаторы,
синтаксис Python-примеров и существование упомянутых тестовых функций.
Покрытие не измерялось; реальные запросы Bitrix не выполнялись.

Регистрация в Telegram, пользователи, расписания, предупреждения, календарь,
корпоративные сроки дат и документы бота относятся к приложению-потребителю.
Здесь не выбираются фреймворк или СУБД будущего бота.
